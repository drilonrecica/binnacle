# Binnacle brand assets

A binnacle is the housing that keeps a ship's compass readable in any weather.
The mark is the compass card inside it: a ring, a north needle, a faint
east-west needle and a hub. Its material is brass on slate. The design is
specified in `imp-docs/DESIGN.md` §Logo, and the colours and type are recorded
in [ADR 027](../../adr/027-headroom-design-system.md).

Every file here is generated by `scripts/brand-assets.py` from a single
description of the mark. Do not edit the SVGs by hand. Change the script and
run it again (see [Regenerating](#regenerating)).

- `landing/assets/`: the same favicons, `binnacle-social.png` and
  `brand/binnacle-mark.svg`.

## The mark

Geometry on a 24-unit grid, centred at (12, 12):

- Ring radius 10.5, stroke 1.5.
- North needle: a diamond from (12, 2.5) to (12, 21.5), half width 2.2 at the
  hub.
- East-west needle: the same diamond turned 90 degrees, at 45 percent opacity.
- Hub: a hole of radius 1.7 through both needles (an even-odd subpath, not a
  filled circle), so the surface shows through on any background.

The 16 and 32 px drawings are simplified for small sizes. Both drop the
east-west needle and the hub. At 32 px the ring stroke is 1.8. At 16 px the
ring stroke is 2.4, the needle runs from 3 to 21 and its half width is 2.5.
`favicon.svg` uses the 16 px drawing because tabs show it at 16 CSS pixels.

The app icon draws a smaller card (ring radius 8, stroke 1.6, needle from 4.5
to 19.5) on a brass tile, so the ring keeps a margin inside the tile's
rounded corners.

The arc gauges on the Headroom page use the same ring stroke weight and needle
shape, so the mark and the instruments belong to one family.

## Wordmark and lockup

- "Binnacle" in Barlow Condensed SemiBold (600), letter-spacing -0.01 em,
  converted to outlines with the font's own kerning. It needs no installed
  font.
- Lockup: the mark's ring is 1.2× the cap height across and is centred on the
  capitals. The gap between the ring and the B is 0.5× the cap height.
- Brass mark with cream text on dark; slate mark with slate text on light.

## Using it

- **Clear space:** keep at least 0.5× the cap height clear around the lockup.
  Around the mark alone, that is about 0.4× the ring's width.
- **Minimum size:** 24 px for the full mark. Below that, use the favicon
  drawings, which are built for 16 and 32 px.
- **Alt text:** the mark beside a visible "Binnacle" or inside a labelled link
  is decorative (`alt=""`). Used alone, its alt text is "Binnacle".
- Don't recolour the mark outside the palette, add a shadow or outline,
  stretch it, rotate the needle, or set the wordmark in another face.
- Don't put the brass mark on light surfaces. It measures about 2:1 on the
  light background (6.7:1 on slate), so use the slate mark there.

## Regenerating

```sh
python3 scripts/brand-assets.py
```

Requirements: Python 3 with `fontTools` and `brotli` (to read the vendored
woff2 fonts in `web/static/fonts/`), `hb-shape` from the HarfBuzz utilities
(for kerning), and ImageMagick built with librsvg (for the PNGs). The script
rewrites every file listed above and the served copies. Commit them together.
